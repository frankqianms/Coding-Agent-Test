## Description
This is a markdown file that demonstrates how to add comments and documentation to markdown files. Markdown files are commonly used for documentation, README files, and notes.

## Features
- Uses markdown syntax for formatting
- Includes headers, lists, and emphasis
- Can contain code blocks and links
- Supports inline comments via HTML: <!-- like this -->

<!-- 
    This is an HTML comment in markdown
    It won't be visible when rendered
    Useful for adding notes that shouldn't appear in the final output
-->

## Usage
This file can be used as a template for creating well-documented markdown files in the project.

## Notes
- Markdown supports **bold** and *italic* text
- You can create [links](https://example.com)
- Code blocks can be inline `like this` or in blocks

```java
// Example code block
public class Example {
    // This is a comment in code
    public static void main(String[] args) {

}
```
