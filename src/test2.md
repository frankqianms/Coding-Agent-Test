## Overview

This is a sample markdown file that demonstrates how comments can be added to markdown documents. Markdown files support both visible documentation and HTML-style comments.

## Features

- **HTML Comments**: Use `<!-- comment -->` for hidden comments
- **Documentation**: Use markdown syntax for visible documentation
- **Code Blocks**: Can include code examples with comments

## Example Code Block

```java
/**
 * Example of commented code in markdown
 */
public class Example {
    // This is a comment
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

## Notes

- This file can be in root or nested folders
- Comments work at any directory depth
- Markdown supports rich formatting with documentation
